## Synthetic Test Fonts

The following minimal fonts are generated by `generate_test_fonts.py` and checked
into the repository. They are original creations of this project.

| Font | Format | License |
|------|--------|---------|
| minimal.ttf | TrueType | Apache 2.0 |
| minimal.otf | CFF/OpenType | Apache 2.0 |
| minimal.bdf | BDF bitmap | Apache 2.0 |
| minimal.pfb | Type 1 PFB | Apache 2.0 |
| minimal.woff | WOFF 1.0 | Apache 2.0 |
| minimal.ttc | TrueType Collection | Apache 2.0 |

Note: `minimal.pcf` is not generated because it requires the `bdftopcf` tool.
To create one: `bdftopcf minimal.bdf > minimal.pcf`
