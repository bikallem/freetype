## Why synthetic fonts for TTC and WOFF?

- **TTC**: Real TTC files (e.g., Noto Sans CJK) are 16MB+ — too large to
  embed in MoonBit test source. TTC is just a collection header wrapping
  regular SFNT data, so TTF/CFF parity testing covers the core parsing.
- **WOFF1**: A legacy format superseded by WOFF2 (Brotli). Modern font
  servers serve WOFF2, making real WOFF1 files hard to find. WOFF1 is
  just a zlib-compressed SFNT wrapper.

## FreeType's own test suite

FreeType bundles only one regression test font (`As.I.Lay.Dying.ttf`).
It relies on CI with external font corpora for comprehensive testing.
Our suite has broader format coverage than FreeType's own tests.
